# Changelog

All notable changes to VRAPress will be documented in this file.

## [1.0.0] — 2026-08-29

### Foundation release

- Established VRAPress as an independent PHP/MySQL CMS product foundation.
- Preserved pages, posts, categories, comments, menus, media, installer, editor, and public routing capabilities.
- Added the product roadmap and formal development change-control process.
- Separated local configuration and secrets from distributable source.
- Began the structured security, reliability, testing, and production-readiness programme.

## [0.2.0]

- Added visitor comments, moderation, and administrator replies.
- Added the primary-menu builder.
- Improved image handling, multi-upload, and media-library insertion.
- Added public image zoom.

## [0.1.0]

- Initial packaged installer and administration dashboard.
