# Changelog

All notable changes to VRAPress will be documented in this file.

## [1.1.1] — 2026-08-29

### Aurora design system

- Introduced an original Blocksy-inspired visual system without WordPress dependencies.
- Redesigned the public header, navigation, footer, article, archive, cards, forms, comments, and responsive layouts.
- Added consistent design tokens for colour, typography, spacing, radii, shadows, and content widths.
- Matched the page/post editor canvas and Style Guide to the public reading experience.
- Improved semantic public markup and corrected the post-page wrapper structure.

## [1.0.1] — 2026-08-29

### Writer experience

- Added an editor Styles menu with curated, reusable content treatments.
- Added a visual Style Guide so writers can preview and apply available styles.
- Made the editor toolbar sticky for convenient formatting in long pages and posts.
- Added matching frontend styles for lead text, notes, tips, warnings, success messages, quotations, and code blocks.

## [1.0.0] — 2026-08-29

### Foundation release

- Established VRAPress as an independent PHP/MySQL CMS product foundation.
- Preserved pages, posts, categories, comments, menus, media, installer, editor, and public routing capabilities.
- Added the product roadmap and formal development change-control process.
- Separated local configuration and secrets from distributable source.
- Began the structured security, reliability, testing, and production-readiness programme.

## [0.2.0]

- Added visitor comments, moderation, and administrator replies.
- Added the primary-menu builder.
- Improved image handling, multi-upload, and media-library insertion.
- Added public image zoom.

## [0.1.0]

- Initial packaged installer and administration dashboard.
