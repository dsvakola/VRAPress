# Admin Guide

## Content

- Pages: create/edit published pages
- Posts: create/edit posts and assign a category
- Categories: create categories for posts
- Media: upload images/PDF and insert into content

## Settings

- General Settings: site title + tagline
- Change Password: admin password

## Tips

- Prefer clean slugs like `about-us`, `admissions`, `news-2026`.
- Use image size presets (Small/Medium/Large/Full) for consistent layout.
